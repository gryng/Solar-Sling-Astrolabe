# SOLAR SLING: ASTROLABE

**天球儀（アストロラーベ）× 七宝焼（クロワゾネ）× ステンドグラス宝石** をテーマにした、`SOLAR SLING` のリッチ・ビジュアルエディションです。

## 特徴

- **高精細プロシージャル・スプライトアトラス (`ArtisanalAtlas`)**
  - 太陽メダリオン、多面カットの琥珀トパーズ、翡翠スプリッター、歯車付き装甲シール、日蝕機雷、サファイア共鳴バンパー、砂時計・イージスメダリオンをすべて `256×256` オフスクリーンキャンバスで事前ベイク。
  - ラピスラズリ石肌粒子・星座線・72目盛り真鍮コンパス・二重回転アストロラーベ盤をリアルタイム描画。
- **Nano Banana / カスタム画像アセット差し替え対応**
  - `./assets/` フォルダに以下の透過PNG／背景画像を配置するだけで、コード変更なしに自動で差し替わります：
    - `assets/bg_astrolabe.png`（背景）
    - `assets/striker_sun.png`（自機）
    - `assets/target_core.png`（琥珀コア）
    - `assets/target_splitter.png`（翡翠スプリッター）
    - `assets/target_armor.png`（装甲シール）
    - `assets/target_mine.png`（日蝕機雷）
    - `assets/bumper_bell.png`（共鳴バンパー）
- **オンラインランキング連携済み**
  - 維持費0円の Google Apps Script + Google Sheets バックエンドに接続済み。
